## Core Products

### Speechmatics API (Speech-to-Text)
The Speechmatics API provides batch and real-time transcription across 55+ languages, with speaker diarization, custom dictionaries, automatic translation, and Voice Intelligence add-ons (summarization, sentiment analysis, entity recognition). Three models sit behind the same API, so moving between them is a choice at request time rather than a new integration: Enhanced for highest accuracy on single-language audio (with a specialist Enhanced Medical variant for clinical use), Standard for the fastest turnaround, and Melia 1 for audio that switches between languages mid-conversation. See our [Speechmatics API tech page](/tech/speechmatics/speechmatics-api) for the full breakdown.

### Voice Agents
Speechmatics powers the listening layer of real-time voice agents, providing turn detection, intelligent segmentation, diarization, speaker focus for multi-speaker scenarios, and preset configurations for a fast start. Developers can build through integration partners LiveKit, Pipecat, and Vapi for the fastest path to production, or the Voice SDK for custom pipelines.

## Key Features

**Multilingual transcription across 55+ languages**
Speechmatics leads accuracy benchmarks in 62% of supported languages on the FLEURS dataset, with 7.88% WER on Kincaid46 for English, surpassing human-level accuracy on that benchmark.

**Flexible deployment**
Speechmatics runs on private SaaS cloud, on-premises, on-device, and via Docker or Kubernetes, making it suitable for data-sensitive industries like healthcare and finance.

**Voice Intelligence add-ons**
Summarization, sentiment analysis, topic detection, chapter generation, and entity recognition layer on top of transcription without requiring additional integration work.

## Use Cases

**Contact center automation**
Real-time transcription and sentiment analysis during calls, combined with the Voice Agents building blocks for automated handling of common queries.

**Clinical transcription**
Speechmatics' Enhanced Medical model targets 93% real-time accuracy and 96% medical keyword recall, covering English, Arabic English, Danish, Dutch, Finnish, French, German, Norwegian, Spanish, and Swedish.

**Media and broadcast**
Batch transcription of audio and video files for subtitling, archiving, and content search across multiple languages.

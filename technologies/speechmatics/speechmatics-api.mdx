# Speechmatics API

The [Speechmatics API](https://www.speechmatics.com/product/transcription) provides batch and real-time transcription across 55+ languages, with speaker diarization, custom dictionaries, automatic translation, and Voice Intelligence add-ons (summarization, sentiment analysis, entity recognition). Multiple models sit behind the same API, so moving between them is a choice made at request time rather than a new integration.

## Core Features

- **55+ languages and dialects**: broad multilingual support including accent and dialect variants.
- **Speaker diarization**: multi-speaker detection included at no extra cost in all plans.
- **Custom dictionary**: up to 1,000 domain-specific words added without retraining.
- **Automatic translation**: transcripts translated into 30+ target languages via AI.
- **Voice Intelligence add-ons**: summarization, sentiment analysis, topic detection, chapter generation, and entity recognition.
- **Audio events detection**: identifies non-speech events in audio.
- **Smart formatting**: formats numbers, dates, currencies, and capitalization automatically.
- **Flexible deployment**: cloud API, on-premises, on-device, Docker, and Kubernetes.

## Models

Three models sit behind the same API: Enhanced, Standard, and Melia 1. Enhanced Medical is a specialist variant of Enhanced, tuned for clinical audio.

| Model | Best for | Regions | Modes |
|-------|----------|---------|-------|
| **Enhanced** | Highest accuracy on single-language audio, such as medical, legal, and subtitling work | EU, US, Australia | Batch, real-time |
| **Enhanced Medical** | Clinical audio like ambient scribes and dictation, tuned to recognize procedures, medications, conditions, and anatomy | EU, US | Batch, real-time (varies by language) |
| **Standard** | Highest throughput and fastest turnaround, for archival transcription, content indexing, or large-scale captioning | EU, US, Australia | Batch, real-time |
| **Melia 1** | Multilingual audio, including speakers who switch language mid-conversation | EU, US | Batch (real-time on the roadmap) |

**Enhanced Medical** is kept up to date using officially maintained clinical data sources. It covers English, Arabic English, Danish, Dutch, Finnish, French, German, Norwegian, Spanish, and Swedish.

**Melia 1** handles code-switching across all supported languages, so a recording that moves between languages comes back as one continuous transcript, with no language to select in advance and no language packs to manage. Output includes per-word language labelling, and accuracy is on par with Standard. It is currently in production preview for batch transcription.

## Voice Agents

Speechmatics powers the listening layer of real-time voice agents. Core building blocks include turn detection, intelligent segmentation that groups partial transcripts into clean speaker-attributed segments, diarization, speaker focus for multi-speaker scenarios, and preset configurations for a fast start.

There are two ways to build:

- **Integration partners**: [LiveKit](https://livekit.io), [Pipecat](https://www.pipecat.ai), and [Vapi](https://vapi.ai) for the fastest path to a production agent, handling audio transport and infrastructure so developers can focus on agent logic.
- **Voice SDK**: for custom pipelines and platforms outside those integrations, giving direct access to turn detection, transcript grouping, and diarization.

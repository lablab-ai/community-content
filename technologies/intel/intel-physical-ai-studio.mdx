# Intel Physical AI Studio

[Physical AI Studio](https://github.com/open-edge-platform/physical-ai-studio) is an end-to-end, open-source framework for teaching robots to perform tasks through imitation learning. It provides a browser-based interface covering the full workflow, from hardware setup and demonstration recording through Vision-Language-Action (VLA) model training and policy execution, and is designed to run on a developer's own hardware.

## Core Features

- **Browser-based UI** — covers hardware setup, dataset recording, model training, and policy execution from a single interface.
- **Imitation learning pipeline** — trains Vision-Language-Action policies from human demonstration data rather than hand-coded control logic.
- **physicalai-train package** — a full-cycle VLA development stack for defining a PyTorch model, benchmarking it, and exporting it to a deployment framework.
- **Heterogeneous deployment** — pairs with [OpenVINO](/technologies/intel/openvino) to run trained policies with low-latency, low-jitter control loops on Intel Core Ultra Series 3 hardware.

---

## Ecosystem and Integrations

- Built to run on Intel Core Ultra Series 2/3 processors, using the onboard NPU and iGPU for training and inference.
- Uses [OpenVINO](/technologies/intel/openvino) as its inference and optimization backend, and LeRobot on PyTorch XPU for policy training.

# Anomalib

[Anomalib](https://github.com/open-edge-platform/anomalib) is an open-source deep learning library focused on visual anomaly detection, the task of finding and localizing defects or irregularities in images and video. First released on PyPI in December 2021, it is maintained under Intel's Open Edge Platform GitHub organization (formerly the OpenVINO Toolkit org) and ships a large collection of state-of-the-art anomaly detection algorithms alongside tools for experiment management, hyperparameter optimization, and edge inference.

## Core Features

- **State-of-the-art algorithm collection** — implements a wide range of visual anomaly detection approaches in a single, benchmarkable codebase.
- **Multiple inference backends** — trained models export and run through Torch, Lightning, Gradio, or OpenVINO Intermediate Representation.
- **Anomalib Studio** — a low-code and no-code web application for training and deploying anomaly detection models without writing Python.
- **Edge-ready export** — built-in export to OpenVINO IR for accelerated inference on Intel CPUs, GPUs, and NPUs.

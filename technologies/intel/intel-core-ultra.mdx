# Intel Core Ultra

[Intel Core Ultra](https://www.intel.com/content/www/us/en/products/details/processors/core-ultra/series-2.html) is Intel's line of client processors built for AI PCs, pairing a CPU and GPU with a dedicated Neural Processing Unit (NPU) so AI workloads can run locally instead of relying on the cloud. Core Ultra Series 2 (code-named Arrow Lake and Lunar Lake) launched in 2024, and Series 3 processors are the current generation used in Intel's latest Physical AI and edge AI reference designs.

## Core Features

- **Intel AI Boost NPU** — the 200V series NPU delivers up to 48 TOPS, built from two Neural Compute Engine tiles with configurable MAC engines and Movidius SHAVE DSPs.
- **Combined platform performance** — Intel cites up to 120 TOPS of combined CPU, GPU, and NPU AI performance on Core Ultra Series 2.
- **On-device inference** — runs optimized models through [OpenVINO](/technologies/intel/openvino) without a network round trip, reducing latency for vision and language workloads.
- **Robotics and physical AI** — used as the compute target for [Intel Physical AI Studio](/technologies/intel/intel-physical-ai-studio) VLA policies, providing low-latency control loops for robotic systems.

# OpenVINO

[OpenVINO](https://github.com/openvinotoolkit/openvino) (Open Visual Inference and Neural Network Optimization) is Intel's open-source toolkit for accelerating deep learning inference. First released on May 16, 2018, it takes trained models from popular frameworks and compiles them to run efficiently across Intel CPUs, integrated and discrete GPUs, and NPUs, without requiring developers to rewrite their models for each target device.

## Core Features

- **Framework interoperability** — imports models trained in PyTorch, TensorFlow, ONNX, Keras, PaddlePaddle, and JAX/Flax without manual conversion.
- **Heterogeneous execution** — runs the same compiled model across Intel CPUs, GPUs, and NPUs, letting the runtime pick the most efficient device.
- **Generative AI support** — the OpenVINO GenAI repository and OpenVINO Tokenizers add pipelines for running LLMs and diffusion models on Intel hardware.
- **Quantization and compression** — the Neural Network Compression Framework (NNCF) applies quantization, pruning, and sparsity to shrink models for edge deployment.
- **Model serving** — OpenVINO Model Server (OVMS) exposes optimized models as a scalable inference service.

## Tools and Resources

- **OpenVINO Physical AI for Robotics** — extends OpenVINO to robot-policy deployment as part of Intel's Robotics AI Suite.

## Ecosystem and Integrations

- Used as the deployment layer in Intel's [Physical AI Studio](/technologies/intel/intel-physical-ai-studio) VLA workflow, optimizing trained policies for Intel Core Ultra processors.
- Runs across Intel's AI PC lineup (Core Ultra) as well as Xeon servers and Intel Tiber AI Cloud instances.

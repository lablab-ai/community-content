# SiMa.ai

SiMa.ai was founded in 2018 by Krishna Rangasayee and is headquartered in San Jose, California. The company builds a co-optimized hardware and software platform for what it calls "physical AI," bringing computer vision, multimodal language understanding, and generative AI out of the cloud and onto embedded edge devices where power, size, and weight are constrained.

## Core Products

### MLSoC
SiMa.ai's Machine Learning System-on-Chip pairs computer vision and ML acceleration processors with an ARM application processor running Linux, delivering a complete edge inference solution in a low-power package.

### MLSoC Modalix
A multi-modal edge AI product family supporting CNNs, Transformers, LLMs, LMMs, and generative AI at the edge, built for more than 10x the performance per watt of alternative edge chips.

### Palette Software Platform
Palette covers the full model development cycle, from taking a trained model through optimization and compilation to deploying a fully accelerated application on the MLSoC.

## Key Features

**ModelSDK**
Part of Palette, ModelSDK prepares machine learning models for MLSoC deployment, including conversion to lower-precision data types the chip computes more efficiently.

**ModelZoo**
A library of more than 350 precompiled, MLA-ready models drawn from sources like Torchvision, the ONNX Model Zoo, and OpenVINO's Open Model Zoo, letting developers validate workloads without building from scratch.

**Framework-Agnostic Pipeline**
Palette takes a model from any major framework through optimization, packaging, and deployment as an end-to-end accelerated application on SiMa.ai hardware.

## Use Cases

**Embedded Computer Vision**
Run object detection, segmentation, and classification pipelines, including multi-camera setups, directly on MLSoC hardware for robotics, industrial, and smart-camera deployments.

**Generative AI at the Edge**
Deploy LLMs, LMMs, and other generative models on MLSoC Modalix for applications that need physical-world AI without a cloud round trip.

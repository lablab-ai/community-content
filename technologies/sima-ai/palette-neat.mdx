# Palette Neat

[Palette Neat](https://sima.ai/press-release/sima-ai-launches-palette-neat-industrys-first-agentic-environment-for-physical-ai-slashes-development-from-months-to-days/) is SiMa.ai's agentic development environment for Physical AI, launched in 2026 as what the company describes as the industry's first tool of its kind. It combines a Physical AI execution library with an agent workflow layer, letting developers describe a system in natural language rather than hand-writing low-level porting and integration code for new silicon.

## Core Features

- **Natural-language development** — developers issue natural-language commands to build entire application systems, abstracting away low-level compute complexity.
- **Legacy code reuse** — preserves roughly 90% of existing application code when porting to Modalix hardware, rather than requiring a full rewrite.
- **Physical AI execution library** — a purpose-built runtime layer for robotics, automotive, drones, industrial automation, aerospace and defense, smart vision, and healthcare workloads.
- **Hardware pairing** — works with the full-production Modalix MLSoC System-on-Module or its PCIe companion card for high-demand Physical AI deployments.

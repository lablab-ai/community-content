# Evolus AI

[Evolus AI](https://evolus.ai) is an AI orchestration platform that lets companies build agents to run real business processes. Its agents read documents, answer from company knowledge, run automations, and act on the systems a business already uses through APIs and MCP. Developers can bring their own OpenAI-compatible model, including models hosted on AMD infrastructure, and drive the whole platform through a REST API.

## Core Products

### [Evolus REST API](/tech/evolus-ai/evolus-ai-rest-api)
Drives workflows, document extractors, AI tools, and knowledge libraries over HTTP with a single API key.

### [Agent Chat API](/tech/evolus-ai/evolus-ai-agent-chat-api)
Exposes Evolus agents through an OpenAI-compatible endpoint with streaming and conversation continuity.

### [MCP Server](/tech/evolus-ai/evolus-ai-mcp-server)
Lets coding agents and MCP clients build on Evolus directly.

### [Evolus Studio](/tech/evolus-ai/evolus-studio)
A desktop app for macOS, Windows, and Linux with a coding agent that has Evolus tools already connected.

### [Digital Employees](/tech/evolus-ai/evolus-ai-digital-employees)
AI colleagues with their own mailbox and calendar that work in email and Microsoft Teams and attend meetings.

### [AI Switchboard](/tech/evolus-ai/evolus-ai-switchboard)
Answers business phone calls around the clock, books appointments, and transcribes every call.

### Specialized Agents and Automations
Task-specific agents, such as one for invoices, that answer in chat, on a website, or on WhatsApp, plus no-code workflows triggered by emails, WhatsApp messages, or schedules.

## Developer Resources

Everything on the platform is available through the Evolus REST API. Agents can also be reached through an OpenAI-compatible chat endpoint, and an MCP server lets coding agents build on Evolus directly.

<TechTutorials/>

### Integration Points

| Interface | Base URL | Authentication |
|-----------|----------|----------------|
| **REST API** | `https://api.evolus.ai/api/v1` | `X-ApiKey` and `X-Application-Id` headers |
| **OpenAI-compatible agent chat** | `https://api.evolus.ai/v1` | `Authorization: Bearer <application API key>` |
| **MCP server** | `https://api.evolus.ai/mcp` | `X-ApiKey` and `X-Application-Id` headers |

The REST API covers workflow execution, document extractors, AI tools, and knowledge libraries. Only agent chat is OpenAI-compatible, so any OpenAI SDK can point at the `/v1` base URL. List the available agents with `GET /v1/models`, where each ID takes the form `<applicationId>:<agentId>`.

### Bring Your Own Model

Evolus accepts any OpenAI-compatible endpoint, as long as the model supports function calling. Examples from the quickstart include Fireworks AI and a vLLM server running on AMD Developer Cloud. Calls to your own model do not use platform credits.

## Key Features

**Agents that act on real systems**
Agents connect to existing tools through APIs and MCP rather than only answering questions.

**Company knowledge**
Libraries store documents that agents use to answer from company-specific information.

**Model choice**
Use a hosted model or point Evolus at your own OpenAI-compatible endpoint.

---

## Use Cases

**Document processing**
Extract structured JSON, CSV, or text from uploaded files, such as invoices, through document extractors.

**Customer-facing assistants**
Deploy a chat widget or phone switchboard that books appointments and collects contact details.

**Internal digital colleagues**
Run an agent in email and Microsoft Teams that drafts replies and takes meeting minutes.

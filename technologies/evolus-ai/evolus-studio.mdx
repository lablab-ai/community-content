# Evolus Studio

[Evolus Studio](https://evolus.ai/it/evolus-studio) is the Evolus desktop app, positioned as AI that works on your own computer. The developer quickstart describes it as a coding agent with Evolus tools already connected.

| General | |
|---------|--|
| **Developer** | Evolus AI |
| **Type** | Desktop app with coding agent |
| **Platforms** | macOS (Apple Silicon), Windows (64-bit), Linux (x86_64 AppImage or .deb) |
| **Documentation** | [Developer quickstart](https://evolus.ai/developers) |

---

## Core Features

- **Evolus tools built in**: the agent is connected to the Evolus platform without extra MCP setup.
- **Cross-platform**: native builds for macOS, Windows, and Linux.
- **Team model support**: in event workspaces, Studio runs on the model your team has connected.

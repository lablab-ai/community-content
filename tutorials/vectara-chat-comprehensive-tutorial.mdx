## Introduction to Vectara Chat

In this tutorial I will show you how to build, harden, and deploy a multi-turn conversational AI assistant using [Link to Vectara](https://vectara.com/) and its built-in **Vectara Chat** stateful RAG pipeline. If you have ever wired together an embedding model, a vector database, a chunking script, a chat-history memory buffer, and a separate hallucination evaluator during a weekend hackathon, you already know how quickly brittle glue code can slow down a team.

This time I want to show you why Vectara Chat changes that workflow. Instead of managing external conversation memory tables and manual query-rewriting chains, Vectara provides an end-to-end Retrieval-Augmented Generation (RAG) platform that combines:

1. **Boomerang Neural Retrieval + Hybrid Lexical Interpolation:** Blends deep semantic understanding with exact keyword matching for product SKUs, legal clauses, and error codes.
2. **Stateful Multi-Turn Chat (`/v2/chats`):** Automatically stores conversation turns, rewrites ambiguous follow-up questions (*"What if we miss that deadline?"*) using prior context, and returns grounded citations.
3. **Multilingual Cross-Encoder Reranking (`Rerank_Multilingual_v1`):** Promotes the highest-signal passages across 100+ languages before generation begins.
4. **Factual Consistency Score (HHEM):** Runs Vectara's Hughes Hallucination Evaluation Model alongside every generated response so your application can mathematically detect and block unsupported claims in real time.

If you are exploring domain-specific workflows on Lablab, this guide also pairs naturally with the [Vectara Beginner App Tutorial](https://lablab.ai/t/vectara-beginner-app-tutorial-showcase-the-creation-of-vectara-app-in-legal-use-case) and the [Vectara Advanced App Tutorial](https://lablab.ai/t/vectara-advanced-app-tutorial-showcase-the-creation-of-vectara-app-in-legal-or-customer-support-use-case).

## Getting Started with Vectara Chat

### Creating Your Vectara Account and Corpus

Before writing our first line of Python or JavaScript, let's set up a dedicated corpus and API credentials inside the [Link to Vectara Console](https://console.vectara.com/):

1. **Create a Corpus:** Sign in to the Vectara Console, click **Corpora → Create Corpus**, and name your corpus `enterprise-support-kb` (or `legal-contracts-kb`).
2. **Define Filter Attributes (Metadata):** Add two document-level filter attributes—`department` (`text`) and `jurisdiction` (`text`)—so our chatbot can scope retrieval to specific teams or regions.
3. **Upload Sample Documents:** Upload two or three PDF, Markdown, or DOCX files (for example, a Master Services Agreement or product troubleshooting handbook). Vectara automatically chunks and embeds your documents with Boomerang.
4. **Generate an API Key:** Navigate to **API Keys → Create API Key**, select **QueryService & IndexService** permissions for your corpus, and copy your `VECTARA_API_KEY` and `VECTARA_CORPUS_KEY`.

### Environment Setup

Create a clean project directory and export your credentials so they are never hardcoded in source control:

```bash
mkdir vectara-chat-assistant && cd vectara-chat-assistant
export VECTARA_API_KEY="zwt_your_vectara_api_key_here"
export VECTARA_CORPUS_KEY="enterprise-support-kb"
```

## Building a Chatbot with Vectara

### How Multi-Turn State Works in Vectara Chat

When a user asks an initial question, your application sends a `POST` request to `https://api.vectara.io/v2/chats` with `"chat": {"store": true}`. Vectara returns a unique `chat_id` and `turn_id` alongside the grounded `answer`, `search_results`, and `factual_consistency_score`.

On every subsequent question in the same session, you simply `POST` to `https://api.vectara.io/v2/chats/{chat_id}/turns`. Vectara automatically inspects the previous turns, resolves pronouns and implicit references, retrieves fresh context chunks, and synthesizes the next answer.

### Production Python Client (`vectara_chat_client.py`)

Below is a complete, zero-dependency Python client that manages `chat_id` state, extracts source citations, and enforces a minimum Factual Consistency Score threshold:

```python
from dataclasses import dataclass, field
from typing import Any, Callable, Dict, List, Optional
import json
import os
import urllib.request


@dataclass
class ChatCite:
    score: float
    text: str
    doc_id: str
    metadata: Dict[str, Any] = field(default_factory=dict)


@dataclass
class ChatTurnResult:
    chat_id: str
    turn_id: str
    answer: str
    factual_consistency_score: float
    citations: List[ChatCite]
    passed_hallucination_guard: bool


class VectaraChatAssistant:
    def __init__(
        self,
        api_key: str,
        corpus_key: str,
        min_fcs_threshold: float = 0.70,
        base_url: str = "https://api.vectara.io/v2",
    ):
        self.api_key = api_key
        self.corpus_key = corpus_key
        self.min_fcs_threshold = min_fcs_threshold
        self.base_url = base_url.rstrip("/")
        self.chat_id: Optional[str] = None

    def build_query_payload(
        self,
        user_query: str,
        metadata_filter: Optional[str] = None,
        lexical_interpolation: float = 0.025,
    ) -> Dict[str, Any]:
        corpus_spec: Dict[str, Any] = {
            "corpus_key": self.corpus_key,
            "lexical_interpolation": lexical_interpolation,
        }
        if metadata_filter:
            corpus_spec["metadata_filter"] = metadata_filter

        return {
            "query": user_query,
            "search": {
                "corpora": [corpus_spec],
                "limit": 25,
                "context_configuration": {
                    "sentences_before": 2,
                    "sentences_after": 2,
                },
                "reranker": {
                    "type": "customer_reranker",
                    "reranker_name": "Rerank_Multilingual_v1",
                },
            },
            "generation": {
                "generation_preset_name": "vectara-summary-ext-24-05-med-omni",
                "max_used_search_results": 5,
                "enable_factual_consistency_score": True,
            },
            "chat": {"store": True},
        }

    def ask(self, user_query: str, metadata_filter: Optional[str] = None) -> ChatTurnResult:
        payload = self.build_query_payload(user_query, metadata_filter=metadata_filter)
        endpoint = (
            f"{self.base_url}/chats"
            if self.chat_id is None
            else f"{self.base_url}/chats/{self.chat_id}/turns"
        )
        req = urllib.request.Request(
            endpoint,
            data=json.dumps(payload).encode("utf-8"),
            headers={
                "Content-Type": "application/json",
                "Accept": "application/json",
                "x-api-key": self.api_key,
            },
            method="POST",
        )
        with urllib.request.urlopen(req, timeout=30) as resp:
            raw = json.loads(resp.read().decode("utf-8"))

        self.chat_id = raw.get("chat_id") or self.chat_id or ""
        fcs = float(raw.get("factual_consistency_score", 0.0))
        passed = fcs >= self.min_fcs_threshold
        answer = (raw.get("answer") or "").strip()

        citations = [
            ChatCite(
                score=float(r.get("score", 0.0)),
                text=r.get("text", ""),
                doc_id=r.get("document_id", ""),
                metadata=r.get("document_metadata", {}) or {},
            )
            for r in raw.get("search_results", [])
        ]

        return ChatTurnResult(
            chat_id=self.chat_id,
            turn_id=raw.get("turn_id", ""),
            answer=answer if passed else f"[Low Factual Consistency: {fcs:.2f}] Verify source excerpts.",
            factual_consistency_score=fcs,
            citations=citations,
            passed_hallucination_guard=passed,
        )
```

## Enhancing Chatbot Intelligence

### 1. Tuning Hybrid Search (`lexical_interpolation`)

Pure vector embeddings excel at conceptual similarity but can miss exact alphanumeric identifiers like `ERR-4092`, statute numbers, or part codes. By setting `lexical_interpolation` between `0.025` and `0.10`, Vectara blends BM25-style keyword scoring with Boomerang neural vectors:

- **`0.00`**: Pure neural semantic search (best for open-ended conceptual questions).
- **`0.025 – 0.05`**: Balanced hybrid retrieval (recommended default for customer support and legal workflows).
- **`0.10+`**: Heavy keyword precision (ideal when users paste exact SKU codes, stack traces, or contract clause IDs).

### 2. Scoping Answers with Metadata Filters

In multi-tenant or regulated apps, you rarely want a single query searching across every document ever uploaded. Passing `"metadata_filter": "doc.department = 'legal' AND doc.jurisdiction = 'UK'"` ensures only matching documents enter the reranking and summarization stage.

### 3. Blocking Hallucinations with the Factual Consistency Score (HHEM)

When `"enable_factual_consistency_score": true` is enabled in the `generation` block, Vectara evaluates the generated summary against the retrieved source chunks and returns a calibrated probability between `0.0` and `1.0`. In production, you can display a visual trust badge in your UI:

- **`FCS >= 0.80`**: High-confidence grounded answer (Green badge).
- **`0.65 <= FCS < 0.80`**: Moderate confidence; highlight inline citations for the user to inspect (Amber badge).
- **`FCS < 0.65`**: Trigger an automatic fallback showing the raw top-ranked excerpts rather than risking a hallucinated synthesis.

## Deploying and Testing Chatbots

### Drop-in React / Web UI Integration (`@vectara/react-chatbot`)

For rapid frontend deployment, Vectara maintains the open-source [Link to Vectara React Chatbot Widget](https://github.com/vectara/react-chatbot), or you can call your backend proxy directly from vanilla JavaScript:

```javascript
async function sendChatTurn(question, existingChatId = null) {
  const response = await fetch("/api/vectara-chat", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ query: question, chatId: existingChatId }),
  });
  const data = await response.json();
  console.log("Answer:", data.answer);
  console.log("Factual Consistency Score:", data.factual_consistency_score);
  return data;
}
```

### Automated Unit Testing Before Launch

Never wait until live demo day to discover a broken payload schema. Using dependency injection on the HTTP transport layer (as shown in `vectara_chat_client.py`), you can unit-test both `/v2/chats` session creation and `/v2/chats/{chat_id}/turns` follow-ups offline in milliseconds:

```bash
python3 -m unittest test_vectara_tutorial_snippets.py -v
```

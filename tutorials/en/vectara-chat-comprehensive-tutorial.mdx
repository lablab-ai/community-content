## Introduction to Vectara Chat

In this tutorial I will show you how to build, customize, and deploy a grounded multi-turn conversational assistant using **Vectara Chat**. Modern Generative AI applications often struggle with two critical engineering challenges: maintaining coherent context across multi-turn conversations and eliminating hallucinations when answering domain-specific questions.

Vectara solves both problems out of the box by combining neural retrieval (**Boomerang** embeddings), hybrid lexical search, cross-encoder reranking, and grounded generation with built-in **Hughes Hallucination Evaluation Model (HHEM)** scoring. If you want to explore foundational legal and customer-support workflows on lablab.ai, check out the [Vectara Beginner App Tutorial](https://lablab.ai/t/vectara-beginner-app-tutorial-showcase-the-creation-of-vectara-app-in-legal-use-case) and the [Vectara Advanced App Tutorial](https://lablab.ai/t/vectara-advanced-app-tutorial-showcase-the-creation-of-vectara-app-in-legal-or-customer-support-use-case).

## Getting Started with Vectara Chat

This time I want to show you how quickly you can go from zero to an authenticated Vectara Chat workspace:

1. **Create a Vectara Account & Corpus**:
   - Sign in to the [Vectara Console](https://console.vectara.com/) and create a new corpus (for example, `product-knowledge-base`).
   - Note your **Customer ID** (`customer_id`) and **Corpus ID** (`corpus_id`).
2. **Generate an API Key**:
   - Navigate to **Access Control -> API Keys** and create a key with **QueryService** and **IndexService** permissions.
3. **Set Up Your Python Environment**:

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install requests streamlit python-dotenv
```

Create a `.env` file in your project root:

```ini
VECTARA_CUSTOMER_ID=your_customer_id
VECTARA_CORPUS_ID=your_corpus_id
VECTARA_API_KEY=your_api_key
```

## Building a Chatbot with Vectara

When `chat.store` is enabled in a Vectara query, Vectara automatically persists the conversation (`conversation_id`) and rewrites follow-up user questions (such as *"How much does it cost?"* or *"Does it support SSO?"*) into self-contained retrieval queries using the prior turn history.

Let's create `vectara_chat_client.py` to handle both document indexing and stateful multi-turn chat:

```python
import os
from typing import Any
import requests


class VectaraChatClient:
    """Stateful client for Vectara Chat and hybrid retrieval."""

    def __init__(self, customer_id: str, corpus_id: int, api_key: str) -> None:
        self.customer_id = customer_id
        self.corpus_id = int(corpus_id)
        self.api_key = api_key
        self.query_url = "https://api.vectara.io/v1/query"

    def ask(
        self,
        user_message: str,
        conversation_id: str | None = None,
        lambda_lexical: float = 0.025,
        max_results: int = 5,
    ) -> dict[str, Any]:
        chat_config: dict[str, Any] = {"store": True}
        if conversation_id:
            chat_config["conversationId"] = conversation_id

        payload = {
            "query": [
                {
                    "query": user_message,
                    "start": 0,
                    "numResults": max_results,
                    "contextConfig": {
                        "sentencesBefore": 2,
                        "sentencesAfter": 2,
                    },
                    "corpusKey": [
                        {
                            "customerId": int(self.customer_id),
                            "corpusId": self.corpus_id,
                            "lexicalInterpolationConfig": {"lambda": lambda_lexical},
                        }
                    ],
                    "rerankingConfig": {
                        "rerankerId": 272725718  # MMR / Maximal Marginal Relevance reranker
                    },
                    "summary": [
                        {
                            "maxSummarizedResults": max_results,
                            "responseLang": "en",
                            "chat": chat_config,
                            "factualConsistencyScore": True,
                        }
                    ],
                }
            ]
        }

        headers = {
            "Content-Type": "application/json",
            "Accept": "application/json",
            "customer-id": str(self.customer_id),
            "x-api-key": self.api_key,
        }
        response = requests.post(self.query_url, json=payload, headers=headers, timeout=30)
        response.raise_for_status()
        data = response.json()

        resp_set = (data.get("responseSet") or [{}])[0]
        summary_block = (resp_set.get("summary") or [{}])[0]
        chat_block = summary_block.get("chat") or {}

        return {
            "answer": summary_block.get("text", ""),
            "conversation_id": chat_block.get("conversationId") or conversation_id,
            "fcs_score": summary_block.get("factualConsistency", {}).get("score"),
            "citations": resp_set.get("response", []),
        }
```

## Enhancing Chatbot Intelligence

To get production-grade accuracy out of Vectara Chat, combine three capabilities:

1. **Hybrid Lexical + Neural Interpolation (`lambda`)**:
   - Setting `lambda` between `0.02` and `0.05` blends Boomerang semantic embeddings with exact keyword matching—essential for SKUs, legal clauses, error codes, and API identifiers.
2. **Diversity-Aware Reranking (`rerankerId: 272725718`)**:
   - Maximal Marginal Relevance (MMR) prevents redundant chunks from dominating the context window so the LLM synthesizes broader evidence.
3. **Real-Time Factual Consistency Scoring (`factualConsistencyScore: True`)**:
   - Every response returns a calibrated factual consistency probability (`0.0` to `1.0`). If `fcs_score < 0.70`, your UI can display a verification warning or trigger a fallback escalation.

## Deploying and Testing Chatbots

Let's wrap `VectaraChatClient` in an interactive Streamlit web app (`app.py`) that displays citations and factual consistency badges:

```python
import os
import streamlit as st
from dotenv import load_dotenv
from vectara_chat_client import VectaraChatClient

load_dotenv()

st.set_page_config(page_title="Vectara Grounded Chat", page_icon="💬")
st.title("💬 Grounded AI Assistant with Vectara Chat")

if "conversation_id" not in st.session_state:
    st.session_state.conversation_id = None
if "messages" not in st.session_state:
    st.session_state.messages = []

client = VectaraChatClient(
    customer_id=os.environ["VECTARA_CUSTOMER_ID"],
    corpus_id=int(os.environ["VECTARA_CORPUS_ID"]),
    api_key=os.environ["VECTARA_API_KEY"],
)

for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.markdown(msg["content"])

if prompt := st.chat_input("Ask a question about your knowledge base..."):
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    with st.chat_message("assistant"):
        result = client.ask(prompt, conversation_id=st.session_state.conversation_id)
        st.session_state.conversation_id = result["conversation_id"]
        fcs = result.get("fcs_score")
        badge = f" *(Factual Consistency: {fcs:.2%})*" if isinstance(fcs, float) else ""
        answer_md = f"{result['answer']}{badge}"
        st.markdown(answer_md)
        st.session_state.messages.append({"role": "assistant", "content": answer_md})
```

Run the app locally with:

```bash
streamlit run app.py
```

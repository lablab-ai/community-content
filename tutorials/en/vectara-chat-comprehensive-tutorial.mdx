## 1. Introduction to Vectara Chat: The Era of Grounded Generation

In this tutorial, I will show you how to architect, build, optimize, and deploy an enterprise-grade conversational AI assistant powered by **Vectara Chat**. 

Every developer who has attempted to build a production Retrieval-Augmented Generation (RAG) system with generic vector databases and raw LLMs quickly runs into the "RAG Trilemma":
1. **Hallucinations:** LLMs synthesize facts that sound convincing but do not exist in the source literature.
2. **Retrieval Degradation:** Dense vector search alone struggles with specialized jargon, exact part numbers, gene identifiers, and acronyms.
3. **Conversational Drift:** Multi-turn chat sessions lose context, fail to resolve coreferences, or retrieve irrelevant chunks from previous conversational turns.

Vectara solves this with an end-to-end platform for **Grounded Generation (GenAI)**. Rather than forcing you to stitch together embedding models, chunking strategies, vector stores, hybrid BM25 tokenizers, cross-encoders, and prompt orchestration engines, Vectara provides a unified neural search and conversational RAG engine with built-in factual verification.

### Core Architectural Pillars of Vectara Chat

```
       +-------------------------------------------------------------+
       |                     User Query Turn                         |
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |             Conversational Coreference Engine               |
       |  (Expands "How does it compare to its Phase 2?" into full    |
       |   grounded query: "How does Pembrolizumab compare to Phase2")|
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |             Vectara Boomerang Hybrid Search                 |
       |  [Dense Semantic Embedding] <--- Lambda ---> [Exact Lexical]|
       |  (Boomerang-v2 768-dim)                       (BM25 Token)  |
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |                Sliding Window & Metadata Filter             |
       |  (Extracts adjacent context & applies doc_id / tag filters) |
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |               Cross-Attention Neural Reranker                |
       |              (rerank_multilingual_v1 / Rerank-2)             |
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |             Grounded Summarization with Citations           |
       |  (Generates factual response linked strictly to search IDs) |
       +------------------------------+------------------------------+
                                      |
                                      v
       +-------------------------------------------------------------+
       |          Hughes Hallucination Evaluation Model (HHEM)        |
       |  (Scores factual consistency score 0.00 - 1.00 before delivery)|
       +-------------------------------------------------------------+
```

1. **Boomerang Neural Embeddings:** Vectara's proprietary multi-lingual dense embedding model trained specifically for retrieval and asymmetric question-answering.
2. **Hybrid Search (Dense + Lexical):** Controlled via a single parameter ($\lambda \in [0, 1]$), fusing BM25 exact-match scoring with dense semantic vectors.
3. **Hughes Hallucination Evaluation Model (HHEM):** An open-source, industry-standard neural hallucination detector that scores the factual alignment between retrieved source citations and the generated response (0.0 to 1.0).
4. **Stateful Turn Management:** Vectara Chat tracks session history, conversation turns, and citation lineages natively, eliminating the need to maintain cumbersome custom memory buffers.

```python
"""
scripts/create_vectara_corpus.py
Creates an enterprise corpus configured for conversational chat with custom metadata filters.
"""
import os
import requests
from dotenv import load_dotenv

load_dotenv()

CUSTOMER_ID = os.environ["VECTARA_CUSTOMER_ID"]
API_KEY = os.environ["VECTARA_API_KEY"]
BASE_URL = os.environ.get("VECTARA_API_URL", "https://api.vectara.io")

def create_corpus(corpus_name: str, description: str):
    url = f"{BASE_URL}/v2/corpora"
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "x-api-key": API_KEY,
    }
    payload = {
        "name": corpus_name,
        "description": description,
        "queries_are_answers": False,
        "documents_are_questions": False,
        "encoder_id": 1,  # Boomerang encoder
        "filter_attributes": [
            {
                "name": "document_type",
                "level": "document",
                "description": "Category of document (e.g. clinical_trial, 10k_filing, research_paper)",
                "indexed": True,
                "type": "text"
            },
            {
                "name": "publication_year",
                "level": "document",
                "description": "Calendar year of publication or filing",
                "indexed": True,
                "type": "integer"
            },
            {
                "name": "ticker_or_sponsor",
                "level": "document",
                "description": "Stock ticker or clinical trial sponsor organization",
                "indexed": True,
                "type": "text"
            }
        ]
    }

    response = requests.post(url, json=payload, headers=headers)
    if response.status_code in (200, 201):
        corpus_data = response.json()
        print(f"[+] Corpus created successfully! ID: {corpus_data.get('id', corpus_data)}")
        return corpus_data
    else:
        print(f"[-] Failed to create corpus ({response.status_code}): {response.text}")
        response.raise_for_status()

if __name__ == "__main__":
```

## 3. Building a Chatbot with Vectara: Python Backend & React Interface

Now that our knowledge base is ingested, let's build the interactive chatbot engine. 

Vectara Chat provides stateful conversations through its **Chat Sessions API** (`/v2/chats`). A chat session retains the turn history, automatically resolves coreferences (e.g., when the user asks *"What were its side effects?"*, the system understands *"its"* refers to *"Neo-Kinase-7"* from turn 1), and appends grounded citations.

### Step 3.1: Python Async Chat Client & Session Manager

```python
"""
vectara_chat_engine.py
Production-grade Vectara Chat Session Manager supporting multi-turn conversation threads.
"""
from __future__ import annotations

import os
import json
import logging
from typing import Any, Dict, List, Optional
import requests
from dotenv import load_dotenv

load_dotenv()
logger = logging.getLogger("vectara_chat")
logging.basicConfig(level=logging.INFO)

class VectaraChatBot:
    def __init__(
        self,
        customer_id: Optional[str] = None,
        corpus_id: Optional[str] = None,
        api_key: Optional[str] = None,
        base_url: str = "https://api.vectara.io"
    ):
        self.customer_id = customer_id or os.environ["VECTARA_CUSTOMER_ID"]
        self.corpus_id = corpus_id or os.environ["VECTARA_CORPUS_ID"]
        self.api_key = api_key or os.environ["VECTARA_API_KEY"]
        self.base_url = base_url.rstrip("/")
        self.headers = {
            "Content-Type": "application/json",
            "Accept": "application/json",
            "x-api-key": self.api_key,
        }

    def create_chat_session(self, initial_system_prompt: Optional[str] = None) -> str:
        """
        Initializes a stateful multi-turn conversation thread.
        Returns the unique chat_id.
        """
        url = f"{self.base_url}/v2/chats"
        payload = {}
        if initial_system_prompt:
            payload["system_prompt"] = initial_system_prompt

        resp = requests.post(url, json=payload, headers=self.headers)
        if resp.status_code in (200, 201):
            chat_id = resp.json().get("id")
            logger.info(f"[+] Started new Vectara Chat Session: {chat_id}")
            return chat_id
        else:
            logger.error(f"Failed to create chat session: {resp.text}")
            resp.raise_for_status()

    def send_turn(
        self,
        chat_id: str,
        user_query: str,
        lambda_val: float = 0.025,
        rerank_limit: int = 5,
        metadata_filter: Optional[str] = None
    ) -> Dict[str, Any]:
        """
        Submits a new query turn within an existing chat session.
        Applies hybrid search, neural reranking, and citation synthesis.
        """
        url = f"{self.base_url}/v2/chats/{chat_id}/turns"
        
        # Build search configuration
        search_corpus_config: Dict[str, Any] = {
            "corpus_key": self.corpus_id,
            "lexical_interpolation": lambda_val,  # 0.0 = pure neural, 1.0 = pure BM25
            "semantics": "default",
        }
        if metadata_filter:
            search_corpus_config["metadata_filter"] = metadata_filter

        payload = {
            "query": user_query,
            "search": {
                "corpora": [search_corpus_config],
                "reranker": {
                    "type": "customer_reranker",
                    "reranker_id": "rnk_272725719",  # rerank_multilingual_v1
                    "limit": rerank_limit
                }
            },
            "generation": {
                "generation_preset_name": "vectara-summary-ext-24-05-med-omni",
                "max_used_search_results": rerank_limit,
                "enable_factual_consistency_score": True
            }
        }

        resp = requests.post(url, json=payload, headers=self.headers)
        if resp.status_code in (200, 201):
            turn_data = resp.json()
            answer_text = turn_data.get("answer", "")
            fcs = turn_data.get("factual_consistency_score", 0.0)
            citations = turn_data.get("rendered_citations", [])
            
            logger.info(f"[Turn Completed] HHEM Factual Score: {fcs:.4f}")
            return {
                "turn_id": turn_data.get("id"),
                "answer": answer_text,
                "factual_consistency_score": fcs,
                "citations": citations,
                "raw_response": turn_data
            }
        else:
            logger.error(f"Error executing turn on chat {chat_id}: {resp.text}")
            resp.raise_for_status()
```

## 4. Enhancing Chatbot Intelligence: Tuning, Filters & Reranking

A naive vector search often fails when dealing with enterprise data. In this section, I will walk you through the four tuning levers that turn an ordinary chatbot into a specialized domain expert.

### 4.1 Hybrid Search Lambda ($\lambda$) Optimization
Vectara blends dense neural semantic search ($s_{dense}$) with BM25 lexical token matching ($s_{lexical}$) using the linear weighting formula:

$$S_{hybrid} = (1 - \lambda) \cdot s_{dense} + \lambda \cdot s_{lexical}$$

| $\lambda$ Value | Search Mode | Best Use Case |
| :--- | :--- | :--- |
| **0.00** | Pure Dense Vector | Conceptual questions, thematic summarization, paraphrased inquiries. |
| **0.025 (Default)** | Semantic Favored | General Q&A with slight boost for rare medical terms or author names. |
| **0.20 – 0.40** | Balanced Hybrid | Biopharma & Financial: Specific drug names (`EGFR T790M`), SEC tickers (`PFE`), serial numbers. |
| **1.00** | Pure BM25 Lexical | Exact alphanumeric codes, UUID lookups, exact regex-style strings. |

```python
# Tuning Lambda dynamically based on query characteristics
def calculate_optimal_lambda(query: str) -> float:
    # If the query contains specialized alphanumeric codes, increase lexical weight
    tokens = query.split()
    has_alphanumeric_code = any(any(c.isdigit() for c in t) and any(c.isalpha() for c in t) for t in tokens)
    if has_alphanumeric_code:
        return 0.35  # Boost exact keyword matching
    return 0.025     # Default semantic primacy
```

### 4.2 Cross-Attention Neural Reranking (`rerank_multilingual_v1`)
Vectara incorporates a cross-encoder model that scores query-document pairs simultaneously, capturing subtle linguistic nuances that single-vector dot products miss.

In our payload, we specify:
```json
"reranker": {
    "type": "customer_reranker",
    "reranker_id": "rnk_272725719",
    "limit": 5
}
```
*Why this matters:* If the initial retrieval retrieves 50 chunks, the cross-attention reranker narrows down to the 5 most factually pertinent chunks before sending them to the LLM prompt, slashing hallucinations and context token costs by over 70%.

### 4.3 Metadata Filtering SQL Expressions
Vectara allows SQL-like filtering on indexed attributes without sacrificing search speed:

```python
# Filter only Phase 3 clinical trials published in 2025 or 2026
filter_expr = "doc.document_type = 'clinical_trial' and doc.publication_year >= 2025"

# Combine with company ticker
ticker_filter = "doc.ticker_or_sponsor = 'BioGenX-Therapeutics'"
```

### 4.4 Custom Grounded Prompt Templates
You can customize the tone, citation formatting, and fallback behavior by supplying a custom prompt template to the generation request:

```json

}
```

### Step 5.1: FastAPI Streaming Gateway (`app.py`)

```python
"""
app.py
High-throughput FastAPI gateway exposing Vectara Chat with HHEM factual safety gate.
"""
from fastapi import FastAPI, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field
from typing import Optional, List
import os

from vectara_chat_engine import VectaraChatBot

app = FastAPI(
    title="Vectara Grounded Chatbot Microservice",
    description="High-fidelity conversational API with HHEM zero-hallucination verification.",
    version="1.0.0"
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

bot = VectaraChatBot()

class CreateSessionResponse(BaseModel):
    chat_id: str
    status: str

class TurnRequest(BaseModel):
    query: str = Field(..., example="What was the median Progression-Free Survival in the trial?")
    lambda_val: Optional[float] = Field(0.025, ge=0.0, le=1.0)
    metadata_filter: Optional[str] = None

class TurnResponse(BaseModel):
    turn_id: str
    answer: str
    factual_consistency_score: float
    hallucination_risk: str
    citations: List[dict]

@app.get("/health")
def health_check():
    return {"status": "HEALTHY", "service": "vectara-chat-gateway"}

@app.post("/api/chat/session", response_model=CreateSessionResponse)
def create_session():
    try:
        cid = bot.create_chat_session()
        return {"chat_id": cid, "status": "CREATED"}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.post("/api/chat/{chat_id}/turn", response_model=TurnResponse)
def submit_turn(chat_id: str, req: TurnRequest):
    try:
        result = bot.send_turn(
            chat_id=chat_id,
            user_query=req.query,
            lambda_val=req.lambda_val,
            metadata_filter=req.metadata_filter
        )
        
        fcs = result["factual_consistency_score"]
        # HHEM Safety Thresholding: Scores above 0.85 are high-confidence grounded
        risk_level = "LOW_RISK" if fcs >= 0.85 else ("MEDIUM_RISK" if fcs >= 0.70 else "HIGH_HALLUCINATION_RISK")
        
        return {
            "turn_id": result["turn_id"],
            "answer": result["answer"],
            "factual_consistency_score": fcs,
            "hallucination_risk": risk_level,
            "citations": result["citations"]
        }
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```
